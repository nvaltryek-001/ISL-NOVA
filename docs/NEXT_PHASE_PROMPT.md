## PHASE 2: MODEL ACCURACY AND ROBUSTNESS

1. **Frame-rate robustness (highest priority).**
   - Add augmentation in `ml/isl_nova_ml/augment.py`: random temporal subsampling simulating 8–30 fps, frame jitter, dropped frames and short occlusions.
   - Retrain LSTM / GRU / LogReg via `include-train.yml`.
   - Re-run `include-live-eval.yml` (virtual camera).
   - **Target:** browser top-1 ≥ 85 % while INCLUDE test top-1 stays ≥ 90 %.
   - Report before/after honestly, whatever the outcome.
2. **Signer and camera robustness.** Augment hand scale, rotation (±15°), translation, camera distance and left-hand mirroring (with correct handedness swap); add tests.
3. **Unknown-sign rejection.**
   - Implement and compare: max-softmax (baseline), energy score, Mahalanobis / class-centroid distance, and an explicit `__other__` class trained on held-out glosses plus idle and fidget movement.
   - Use separate gloss sets for training the `__other__` class and for evaluating it (no leakage).
   - **Target:** false acceptance < 10 % with false rejection ≤ 15 %.
   - Write `research/OPEN_SET_V2.md`.
4. **Stronger models.**
   - Add PyTorch implementations (CPU-friendly): Temporal Convolutional Network (TCN), a small Transformer encoder, and BiLSTM with attention.
   - Same feature contract, same splits, selection on validation only.
   - Run 3 seeds each and report mean ± std.
   - Keep NumPy models as a no-dependency fallback.
5. **Face / non-manual features (contract v2).**
   - Add `isl-nova-fc-2.0.0` with MediaPipe Face Landmarker features (eyebrows, eyes, mouth shape, head pose).
   - Keep v1 working, with versioned models and registry entries.
   - Re-extract with an updated `include-data.yml`; run an ablation of hands vs hands+pose vs hands+pose+face.
6. **In-browser inference.**
   - Export the best model to ONNX (`ml/isl_nova_ml/export.py`) and run it in the browser with `onnxruntime-web` (pinned CDN).
   - Fall back to the server when it is unavailable.
   - Prove parity: browser vs Python outputs within 1e-4 on fixtures. Measure latency.
7. **Model card and registry.** Update `docs/MODEL_CARD.md` for every promoted model; never auto-promote; keep rollback.
