# ISL NOVA 2.0.0

The 200-sign platform in three languages, with a stronger model that also says "I don't know".

## Results (genuine runs; INCLUDE official split; not signer-independent)

| | v1 | **2.0.0** | Target |
|---|---:|---:|---|
| Test top-1 / top-5 (635 videos) | 91.7 % / 98.3 % | **95.1 % / 99.4 %** | — |
| Browser pipeline, 73 held-out clips | 74.0 % | **84.9 %** | ≥ 85 % — not met (one clip) |
| Unknown signs accepted (held-out glosses) | 29.3 % | **8.8 %** | < 10 % — met |
| Known signs held back | 12.1 % | **13.2 %** | ≤ 15 % — met |

Default model: [`model-bilstm_attn-20261110T162800Z-s7`](https://github.com/nvaltryek-001/ISL-NOVA/releases/tag/model-bilstm_attn-20261110T162800Z-s7).

## New

- English, Hindi and Kannada everywhere; all 200 meanings in three languages (Hindi/Kannada are machine drafts awaiting linguists).
- Frame-rate augmentation; TCN, Transformer and BiLSTM-attention models; ensembles; unknown-sign detector.
- On-device (offline) recognition in the browser; ONNX export.
- Practice Coach, Text-to-Sign, Conversation (signs split at pauses), teacher classes, analytics, spaced repetition, streaks and badges.
- Refresh tokens, sign out everywhere, reset codes, two-factor sign-in, retention job.
- Redis rate limit and job queue with workers, S3-compatible storage, Prometheus + Grafana, load test.
- Installable offline app; WCAG 2.1 AA scan in CI.
